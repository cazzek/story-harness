# シナリオの状態抽出

`docs/シナリオ制作ハーネス.md` に従う。同じ作業領域の文脈、構成案、本文案を読み、参照元のSHA-256と未作成状態を照合する。途中変更があれば先行工程へ戻る。

1. 台詞、内心、行動、選択肢、画面表示などを、本文ブロックの識別子付きで確認する。明示、示唆、不確実を分ける。
2. 作中の事実、人物が知る、信じる、疑う内容、読者への直接開示と推測を別に抽出する。台詞の中の主張を、作中の真実とみなさない。
3. 差分へ、時点、条件、必要フラグと本文根拠を付ける。別の選択肢や周回から知識を合算しない。物語上のフラグと、システム側の解放履歴を分ける。
4. 関係は、誰から誰へ、どの軸の変化かを記録する。伏線は既存のIDを優先し、設置、補強、回収を分ける。作品に存在しない数値パラメータを作らない。
5. 新たな作中の真実や作者意図は、未採用候補へ隔離する。不確実な推測を確定差分にしない。本文案にない出来事を抽出しない。
6. `シナリオ管理/書式/状態抽出.md` を使い、同名の作業ファイルへ保存する。

抽出結果は未採用である。現在の台帳、正本、本文、採用履歴へ反映しない。次は `story-review`。
