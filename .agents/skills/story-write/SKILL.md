# シナリオの執筆

`docs/シナリオ制作ハーネス.md` に従い、同じ作業領域の `文脈.md` と `構成案.md` を読む。参照元のSHA-256と未作成状態を照合する。途中変更があれば先行工程を更新する。本文を書く、直すときは、作品の文体ガイドにも従う。

1. 対象本文の前後から、語彙、間、独白、選択肢の調子を拾う。作者の文章が特定できる場合は優先する。他の作品の語り口や人物の癖を持ち込まない。
2. 人物設定と、この時点での知識を守る。人物が知らないことや、正本で伏せることに決まっている内容を読者へ渡さない。
3. 構成案の狙い、対象外、時点、条件、開示境界を守る。口語や間、反応を保ち、一般的な説明台詞へ均さない。
4. 本文ブロックに識別子を付ける。選択肢がある作品では、条件、各枝と合流点、次に進む先を明示する。既存の変数名や識別子は保持し、新規が必要なら候補として説明する。
5. ファイルと範囲ごとの置換、追加、削除と、接続や戻り値への影響を、適用対応表に示す。同期すべき索引、台帳も限定する。
6. 新しい固有名、設定、秘密の開示が混ざっていないか正本と照合する。新設定は候補へ分ける。
7. `シナリオ管理/書式/本文案.md` を使い、同名の作業ファイルへ保存する。

既存の本文、正本、台帳、採用履歴は変更しない。次は `story-extract`。
