# 文体ガイド（ひな形）

自分の作品の文体と表記のルールを書くためのひな形です。項目は一例です。不要な項目は消し、必要な項目を足してください。決めたルールは、執筆、改稿、レビューのときに参照し、外部の改稿者に依頼するときはガイドの全文を渡します。

## 記入欄

### 地の文

- 人称と視点:
- 文の長さの目安:
- 独白、内心の表記（括弧の種類など）:
- 台詞の表記:

### 句読点

- 読点の打ち方の方針:
- 地の文一文あたりの読点の上限の目安:
- 台詞、内心、擬音の中の読点の扱い:
- 三点リーダ等の記号の前後の扱い:

同梱の `scripts/読点チェック.py` は、本文ファイルの読点を、地の文、台詞、内心に分けて数え、読点が多い文を表示する簡易ツールです。自分の目安に合わせて判定に使えます。

### 語彙と表記

- 避けたい曖昧な言い回しと、寄せたい直接の言い回し:
- 統一したい表記（同じ対象への呼び方、擬音や擬態の表記ゆれなど）:
- 序盤では使わない専門用語など、段階で解禁する語彙の扱い:

### 比喩と内省

- 比喩の使い方の方針:
- 内省や説明の分量の目安:

### 作者の修正から学んだこと

作者が過去の本文を直した差分から読み取った好みは、ここに日付とともに追記していくと、作品固有の文体ガイドに育ちます。意図して残された表記は、ルールで一律に直さないでください。
