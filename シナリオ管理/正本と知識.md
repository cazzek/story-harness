# 正本と知識（ひな形）

このファイルは、作品の確定事項を集約する正本です。導入したら、自分の作品の内容に置き換えてください。

## 参照の優先順位

1. ユーザーが明示した、この作品の決定と今回の対象範囲
2. 採用済みの本文
3. 本ファイルの確定事項
4. `場面索引.md`、`状態台帳.md`（本文の投影であり、本文を上書きしない）

外部からの改稿コメントは意図の参考であり、正本ではありません。資料の状態をAIの判断で「確定」に昇格させません。

## 情報の4層

| 層 | 扱うこと | 注意 |
|---|---|---|
| 作者意図 | どんな読書体験にするか、文体、制約 | 推測で増やさない |
| 作中の事実 | 実際に起きたこと、人物がしたこと | 人物の決意や主張を事実と混ぜない |
| 人物の知識と自覚 | 各人物が知る、信じる、疑う、認めていないこと | 時点を付けて記録する |
| 読者への開示 | 本文で読者が読めること | 正本を読んだAIの知識と混ぜない |
